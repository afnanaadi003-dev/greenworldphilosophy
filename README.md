# GreenWorld website

A responsive, single-page GreenWorld philosophy website — mission, vision, philosophy, and a browser-generated library of **50,000 green alternatives**.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.

No build tools, API keys, or paid services are required.

## The 50,000-alternatives library
The library is generated live in the browser from three editable lists in `index.html`:

- **HARMS** — 100 harmful things, including every topic requested:
  - poison & harmful chemicals (bleach, pesticides, rat poison, mothballs…)
  - single-use plastic (bags, straws, bottles, sachets…)
  - cutting trees (paper, charcoal, logging, mangroves…)
  - wood elements, furniture & beds (hardwood bed frames, plywood cabinets, treated posts…)
  - polluting buildings (concrete, kiln bricks, asphalt, glass towers…)
  - sleep & wellbeing (sleeping pills, foam pillows, late caffeine, pre-bed screens…)
  - plus energy, water, food, clothes and waste
- **SWAPS** — 50 greener material & habit alternatives (bamboo, coconut coir, rammed earth, refillable, CBT-style habits, solar-powered…)
- **CONTEXTS** — 10 everyday places (home, kitchen, garden, bedroom, farm…)

100 × 50 × 10 = **exactly 50,000 entries**, shown 48 at a time with search (try "bed", "sleeping pill", "poison", "tree", "building", "wood", "plastic") and category tabs.

## Features
- Mission, vision, and philosophy sections
- Searchable 50,000-alternative library with category filters, A–Z sorting, and load-more paging
- Responsive mobile layout
- Interactive pledge button
- Health note: GreenWorld never advises stopping prescribed medicines; sleeping-pill alternatives point to professional care and CBT-I

## Customize
Edit the `HARMS`, `SWAPS`, or `CONTEXTS` arrays in `index.html` (inside the first `<script>` block). Changing the counts changes the total automatically — the badge, title and counters all update.
